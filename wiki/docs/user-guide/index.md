# User guide

Use the sidebar to open Home, media libraries, collections, calendar, inbox, statistics, notifications, settings, and any pages contributed by enabled plugins.

## Libraries

- [Games](games.md) includes metadata, profiles, achievements, screenshots, documents, saves/backups, checklists, and trash recovery.
- [Movies](movies.md), [TV shows](tv-shows.md), and [Anime](anime.md) track progress, ratings, lists, activity, relations, recommendations, and metadata.
- [AniList import](anilist.md) can create or update anime records manually or on a schedule.

## Account and data

- [Authentication](authentication.md) covers passwords, API keys, and account identity.
- [OpenID Connect](oidc.md) covers configured SSO providers.
- [Data, exports, and backups](data-and-backups.md) explains export/import and deployment backups.
- [Plugins](plugins.md) explains consent, plugin pages, settings, and revocation.
- [Notification providers](notification-providers.md) explains external destinations and preference controls.

Actions are scoped to the signed-in account unless the interface explicitly identifies an administrator operation.
