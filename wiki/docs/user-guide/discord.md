# Discord webhook configuration

Discord webhooks are configured per user under Settings → Notification Providers.

Enter a webhook URL from a supported Discord webhook endpoint, then save it. The application validates the destination and stores it encrypted.

After saving, the full webhook URL is not returned to the browser. To change it, enter a replacement webhook. To remove it, use Revoke.

A user can only modify their own provider configuration. Discord delivery is disabled automatically when no webhook is configured.
